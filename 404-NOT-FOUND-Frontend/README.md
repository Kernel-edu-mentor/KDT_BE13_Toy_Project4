⚙️ 코드 수정 방법

Lovable 프로젝트를 수정하는 방법은 여러 가지가 있습니다.

1️⃣ Lovable 플랫폼에서 직접 수정
	•	위 링크로 이동하여 프롬프트를 입력하면 됩니다.
	•	Lovable을 통해 수정하면 변경사항이 자동으로 GitHub 저장소에 커밋됩니다.

⸻

2️⃣ 로컬 IDE(예: VS Code)에서 수정

자신의 개발 환경에서 코드를 편집하고 GitHub으로 푸시할 수도 있습니다.
이 경우, 변경사항은 Lovable에도 자동 반영됩니다.

사전 준비:
Node.js와 npm이 설치되어 있어야 합니다.
(설치 방법: nvm 설치 가이드)

로컬 실행 단계

# 1. 저장소 클론
git clone <YOUR_GIT_URL>

# 2. 프로젝트 폴더로 이동
cd <YOUR_PROJECT_NAME>

# 3. 필요한 패키지 설치
npm i

# 4. 개발 서버 실행 (자동 새로고침 및 미리보기)
npm run dev


⸻

3️⃣ GitHub에서 직접 수정
	•	수정할 파일로 이동
	•	오른쪽 상단의 ✏️ Edit(연필 아이콘) 클릭
	•	변경 후 Commit changes 클릭

⸻

4️⃣ GitHub Codespaces 사용
	•	저장소 메인 페이지에서 Code (초록색 버튼) 클릭
	•	Codespaces 탭 선택 후 New codespace 실행
	•	웹 IDE 환경에서 수정 후 커밋/푸시 가능

💡 프로젝트 기술 스택

이 프로젝트는 다음 기술로 구성되어 있습니다:

기술	설명
Vite	빠른 프론트엔드 빌드 도구
